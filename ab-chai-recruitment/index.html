剧本编辑 & 最终检查员
招募 1 人

岗位职责

  1. 研读负责人手绘战斗原稿，梳理完整故事线，撰写短片剧本、动作时序、角色对白。
  2. 配合负责人规划镜头序列，整理分镜描述，设计战斗节奏、攻防转换与爆发节点。
  3. 项目全流程协助负责人，每一轮动画版本完成后做最终检查，核对剧情、镜头是否与剧本一致。
  4. 汇总所有修改意见，整理成文档交给负责人，跟进修改落地。

任职要求

  1. 熟悉 AB 柴火柴人风格，喜爱战斗题材动画，逻辑与想象力良好。
  2. 文字表达清晰，能够按期交付约定任务；主动沟通想法，接纳方案迭代调整。
  3. 具备耐心，能够多次复核成片，接受反复修改，不轻言终止项目。
✅ 必备条件：自备电脑 + 拥有本人可用 QQ 账号，用于线上文件传输、团队沟通。

声音 & 特效设计师
招募 1 人

岗位职责

  1. 筛选适配军事基地战斗场景的音效素材：挥击、碰撞、破空、爆炸、枪械、环境背景音；挑选匹配叙事节奏的背景音乐。
  2. 在 Premiere 中完成音频剪辑、音量平衡、音画对齐，添加字幕。
  3. 设计配套画面特效方案：冲击波、闪光、烟尘等战斗特效构思，配合负责人落地特效效果。
  4. 建立音频、特效素材库，规范分类命名，做好素材归档备份。

任职要求

  1. 对声音、画面节奏敏感，能判断音效和特效是否贴合战斗场面。
  2. 无需预先掌握 PR 或特效软件，愿意自学基础操作。
  3. 做事严谨细致，发现音画问题及时反馈，遵守项目进度安排。
  4. 可分配少量课余时间，优先保障学业。
✅ 必备条件：自备电脑 + 拥有本人可用 QQ 账号，用于线上文件传输、团队沟通。

火柴人角色设计师
招募 1 人

岗位职责

  1. 基于 AB 柴火柴人基础画风，为本片设计全部登场火柴人角色：外形、配色、装备、标识。
  2. 根据战斗剧情绘制角色设定稿，区分不同角色的外形特征、作战装备。
  3. 和负责人沟通角色 3D 化可行性，调整设计，保证风格统一。
  4. 记录角色设定文档，更新角色修改版本，保存全部角色原画。

任职要求

  1. 熟悉 AB 柴火柴人画风，能抓住角色线条特点。绘画不需要顶尖水平，造型表达清晰即可。
  2. 能绘制角色设定草图，有想法愿意主动交流。
  3. 有责任心，按约定时间交付角色稿，根据反馈迭代修改设计。
  4. 热爱火柴人动画，愿意打磨角色细节。
✅ 必备条件：自备电脑 + 拥有本人可用 QQ 账号，用于线上文件传输、团队沟通。

项目概述

项目：《火柴人 VS 草稿纸梦想：不知名军事基地》

制作时段：寒假集中制作

本协议由 AB 柴工作室负责人与项目成员共同订立。成员报名并签署本协议，即代表已完整阅读、理解并同意全部条款。

1. 项目概述

  1. 本项目为原创 AB 柴风格火柴人 3D 动画短片《火柴人 VS 草稿纸梦想：不知名军事基地》。主要制作工作安排在寒假；学期阶段仅用于策划、研讨，不安排高强度制作任务，学业优先。
  2. 工作室负责人承担 3D 建模、核心动画制作、项目统筹、美术风格把控。成员按照分配岗位完成对应工作。
  3. 本作品为非商业创作，仅用于校园、班级内部展示交流，无任何劳动报酬。
  4. 团队主要沟通、文件传递方式为 QQ；成员须自备电脑，保障寒假期间可以正常参与线上协作。
  5. 工作室提供 Adobe 软件学习资源与工程模板，软件由成员自行安装。

2. 成员义务

  1. 成员应按岗位约定完成工作，并按期交付成果。如遇学业紧张、时间不足，必须提前主动告知负责人，协商调整任务，不得无故失联、直接放弃项目。
  2. 妥善保管项目全部素材，包含剧本、角色原画、音频资源、动画工程文件，不得擅自删除、篡改、对外转发原始工程。
  3. 团队内部可自由提出创意建议，但短片主线剧情、角色基础画风由负责人拥有最终决定权。
  4. 成员在团队协作中保持理性沟通，避免争执，共同协作解决制作过程中的技术与创意问题。
  5. 保持 QQ 通讯畅通，及时查看团队消息；未完成的半成品、内部工程文件，未经团队共同许可，不得向外部人员传播。成品对外分享须经团队商议。
  6. 素材使用权约定：工作室向成员提供 Adobe 相关学习资源与工程模板。若 AB 柴工作室终止运营，工作室有权通知成员，成员须删除本地存储的本项目全部工程、素材文件。本项目相关创作素材使用权不可继承；成员离世后，相关项目素材不得作为遗产移交。
  7. 保密义务：项目在班级正式展映前，所有剧本、角色设定、分镜、半成品动画、内部构思等信息均为工作室保密资料。成员承诺不向任何第三方透露，包括同学、朋友以及自己的家长。仅当工作室负责人统一发布后，才可以对外介绍本片内容。

3. 署名与版权

  1. 动画片尾将标注工作室名称、负责人及全部项目成员姓名，成员享有作品署名权。
  2. 本项目所有内容版权归属 AB 柴工作室集体所有，成员仅享有署名权；禁止将作品用于售卖、盈利等商业行为。

4. 退出机制

  1. 若成员因学业、家庭等客观原因无法继续参与，需提前与负责人沟通，说明情况，办理退出手续。
  2. 未经沟通擅自失联（QQ 长期不回复）、放弃项目，视为自动退出，片尾不再保留该成员署名。
  3. 成员在退出前已经完成的工作成果，工作室有权继续在本片中使用。
  4. 保密义务不因退出项目而终止，即使中途退出，成员依旧不能泄露项目内部保密内容。

5. 免责约定

  1. Adobe 软件学习存在技术门槛，工作室不承诺成品效果完美；本项目核心目标为团队协作创作、学习动画制作。
  2. 如因设备故障、文件损坏等意外造成素材丢失，团队共同尽力补救，不追究个人责任。
  3. 项目进度将根据寒假作业量灵活调整，不强制熬夜赶工，身体健康与学业优先。
  4. 安全免责：全部创作工作由成员在各自家中独立完成。成员在使用电脑、用电及项目相关操作过程中，如发生任何人身伤害、财产损失，AB 柴工作室及负责人不承担任何责任。成员需自行做好安全防护。

6. 其他约定

  2. 协议条款可经全体成员共同商议修订，修订版本需要所有人确认。
